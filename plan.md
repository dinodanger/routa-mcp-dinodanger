# Plan: the Routa identity MCP server

Scope is the brief's three things: read the settings, change them behind a preview, check the token on every call. Connecting the server to Claude Code, and bringing settings in line with the baseline by asking, come after these steps. Limits (L1 to L11) are in `brain/limits.md`.

- [x] 1. **Server skeleton with the token check.** Newline-delimited JSON-RPC over stdio (`initialize`, `tools/list`, `tools/call`); config from `ROUTA_URL` and `MCP_TOKEN`; a small platform client that calls `whoami` fresh on every tool call and returns `read`, `admin` or "invalid token" as a plain message. Test against a stub platform. (`mcp/src/`, `mcp/test/`)
- [ ] 2. **Read tools.** One tool for who reaches what (by group or by application) and one for policies, in plain words with policy labels. Both work with either token. Test that a read-only token can use them.
- [ ] 3. **Preview tools.** One tool to preview an access change (group, application, allow or deny) and one for a policy change; each returns a preview id and a plain-words description (group gains or loses an application; policy goes from X to Y; "no change" when nothing differs). Admin only: a read-only token is refused. Unknown group, application or policy, and wrong-typed values, are refused at preview with the platform's names listed. Nothing is sent to PATCH.
- [ ] 4. **Apply tool.** `apply_change` takes only a preview id. It checks the scope again, re-reads the settings, and applies exactly the previewed change with one PATCH, or refuses with a reason if the settings moved since the preview or the id is unknown or already used. Test that a read-only token changes nothing and that what was applied equals what was shown.
- [ ] 5. **Live run against the test environment.** Drive the server over stdio with both tokens: read, preview, apply, re-read, undo; read-only refused for preview and apply with the settings unchanged. Then run the verify skill for L1 to L11, and write the server's start command and tool list into `brain/`.
