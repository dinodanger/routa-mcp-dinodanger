## In the loop

Read `plan.md` and the project brain. Pick the first step that isn't done. If all are done and the verify skill reported a problem, pick the step that fixes it. Say in a few lines what to build next and which files it touches. Don't write code.

## A new feature

Check the running services the feature touches, and write what they actually do in the project brain. Draft the steps from the client's files. Suggest the three ideas that would make it much better, then walk the draft for the three open decisions that matter most. Ask each question with the AskUserQuestion tool, a line of background first, your recommendation first. Then write the steps into `plan.md`. Don't write code.
